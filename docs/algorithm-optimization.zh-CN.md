## 仍需明确的边界

“完整优化”不等于无限资源的全局穷尽证明。本次关闭已复现的审计错误并扩展可验证域，但以下限制仍公开保留：

1. 大库存仍受节点、索引、评估次数及时间预算限制；找到合法/精确见证不证明所有配装已遍历。
2. 固定五件硬规则搜索证明可行性，不保证所有软目标的全局最优评分。
3. 最少刷取仅在传入的理论见证及其合法槽位排列内成立，不涵盖上游未展示的全部理论 roll。
4. 极难模糊替换仍可能耗时数十秒；合成超高属性的 cap 测试约 69 秒，不能宣称所有 Upgrade 查询已达到交互级速度。
5. 模组预算仍保留当前安装数量；碎片向量也不等于合法职业分支的枚举证明。
6. 用户原工作区的 `partial/full` 插槽策略没有被自动合并。合并 PR 与本次优化前，仍需单独整合这些未提交改动。
