# v3.1.2

V3.1.2 是 v3.1.0 / v3.1.1 稳定通道上的维护版本，包含 `v3.1.1..develop` 的改动。本版**不改动游戏规则，
也不放宽求解器的证明、证书与见证校验边界**，只撤回一处用户反馈不认可的界面布局变化。

## 界面：恢复固定的工作台输入顺序

v3.1.1 为了让目标属性在窄屏首屏可见，在切换计算模式时由脚本把「目标六维属性」卡片移动到工作区首位，
并把整个工作区移到库存导入卡片之前。这导致页面顺序不再等于 `app/index.html` 中书写顺序：
「碎片属性变化」被压到目标卡片之下，整个目标区域在页面上大幅上移。

维护者反馈不接受这一变化，本版将其撤回：

- 移除 `src/ui/workbench-layout.mjs`，删除其中的 `arrangeWorkbenchInputs()`；该调用同步从
  `setCalculatorMode()` 中移除。
- 工作台恢复为**纯标记定义的静态顺序**：已有护甲导入卡片 → 当前五件护甲卡片 → 工作区
  （碎片属性变化 → 目标六维属性）。切换「从零求解 / 优化现有配装」不再移动任何卡片。
- 键盘焦点顺序与视觉顺序继续一致，因为它们现在由同一份标记同时决定。

需要说明的是，v3.1.1 之前就存在的折叠结构**没有**被本版调整：「高级约束」内始终是
「异域约束」在「套装要求」之前，两版逐行同构。本版未改动套装约束、异域约束、模组与调校等任何
求解输入的语义或位置。

## 保持不变的部分

以下 v3.1.1 的界面与交互改动经确认保留，不属本次撤回范围：

- 优先与规则控件保持为原生下拉选择，取值与三语标签不变。
- 窄屏底部命令栏、可横向滚动的次级操作行保持不变，主操作未被移除。
- 配装详情仍只在显式点击时展开，不随鼠标悬停或键盘聚焦展开。

## 验证

- 新增 `tests/workbench-static-order.test.mjs`：断言标记中工作区卡片顺序为
  「碎片 → 目标」、导入卡片位于工作区之前，且 `src/app.mjs` 中不存在任何在运行时移动这些卡片的调用。
  该测试已验证能在重新引入重排时失败。
- `scripts/verify-workbench-interaction.mjs` 的窄屏检查由「目标卡片进入首屏」改为
  **静态顺序不变**：在「从零求解」与「优化现有配装」之间往返切换后，工作区卡片顺序与顶层区块顺序
  必须保持一致；同时保留主操作按钮可见的几何断言。
- 全量 Node 测试 543 项通过（v3.1.1 为 538 项，新增 5 项）；lint、生产构建、升级计划检查通过。
- 离线自包含构建与桌面前端构建不受影响。

## 已知限制

- 工作台顺序现在完全由标记决定。若日后需要调整，应直接修改 `app/index.html`，使变更可被审查。
- 本版不修改 OAuth 配置、Bungie 写入行为，也不涉及求解算法的证伪或可行性判定边界。
